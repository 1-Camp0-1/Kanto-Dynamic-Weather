# Third-party dependency notice

Kanto Dynamic Weather requires **Dramatic Shape Voxel Mod** (`DRAMATIC_SHAPE`) but does not bundle the Dramatic Shape mod or its full source code.

The `compat/patches/` directory contains narrowly scoped interoperability patches used at runtime against a separately installed compatible Dramatic Shape build. Dramatic Shape remains a separate project by its respective author(s).

Pokémon, Pokémon Red and related names/assets are property of their respective rights holders. This project is an unofficial fan-made modification and does not include a game ROM.
